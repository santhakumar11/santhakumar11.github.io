# Personal Tech Blog

A simple, responsive HTML5 blog designed for GitHub Pages.

## Pages included
- Home
- Blog post
- Archive
- About
- Contact
- RSS feed

## Run locally
Open `index.html` in a browser, or serve the folder with a static server:

```bash
python -m http.server 8000
```

Then visit: `http://localhost:8000`

## Deploy to GitHub Pages
1. Push this folder to your GitHub repository.
2. In the repository settings, enable GitHub Pages.
3. Choose the root folder or a branch as the publishing source.
4. Your site will be available at:
   `https://santhakumar11.github.io/`

## Customize
- Update content in `index.html`, `about.html`, `contact.html`, and `post.html`
- Edit colors and layout in `styles.css`
- Change RSS details in `rss.xml`
